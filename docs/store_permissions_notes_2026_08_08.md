# Разрешения приложения: что писать в магазинах

Дата: 08.08.2026
Касается: RuStore, Google Play, App Store
Статус: действующая договорённость, обновлять при добавлении разрешений

---

## 1. Геолокация

**Заявляем:** доступ к местоположению «при использовании приложения»
(`ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`,
`NSLocationWhenInUseUsageDescription`).

**Формулировка для карточки магазина:**

> Приложение показывает, далеко ли до магазинов, где продаётся выбранное
> вино, и открывает маршрут во внешней карте. Местоположение запрашивается
> только по вашему нажатию и не сохраняется.

Та же формулировка стоит в `NSLocationWhenInUseUsageDescription` — это текст,
который человек видит в системном диалоге iOS, и его же читает проверяющий.
Прежний вариант говорил только про карту покупок и винодельни; после открытия
флага всем он перестал описывать главное применение.

### Что важно сказать проверяющему и не забыть самим

| Утверждение | Как это обеспечено в коде |
|---|---|
| Разрешение **не запрашивается** при запуске и при открытии экрана | Системный диалог поднимает единственная функция `requestLocationAccess`, и вызывается она только из объяснения по нажатию человека |
| Человек сначала видит объяснение, потом системный диалог | `showLocationAccessSheet`: зачем, что уходит, что не сохраняется |
| Функцию можно выключить без новой сборки | Серверный флаг `nearby_places_distance`. С 08.08.2026 открыт всем; пока он выключен, ни значка, ни запроса нет |
| Координаты **не сохраняются** | Ни таблицы, ни колонки: они живут как параметры одного запроса `get_wine_purchase_places`. Ни в логи, ни в аналитику не попадают |
| Координаты огрубляются перед отправкой | Пять знаков после запятой; сырое значение приёмника наружу не уходит |
| Фоновой геолокации нет | `ACCESS_BACKGROUND_LOCATION` не заявляется и не используется |
| Отключить можно в любой момент | Настройки телефона; в профиле показано текущее состояние |

**Где человек управляет этим внутри приложения:** карточка вина, раздел
«Где купить» — значок рядом с переключателем «Списком / На карте»; и профиль,
строка «Расстояние до магазинов» с текущим состоянием.

## 2. Камера

Заявлена для сканирования штрихкодов и QR-кодов чеков и для съёмки этикеток.
Запрашивается в момент открытия сканера, не раньше.

## 3. Галерея

Заявлена для загрузки фотографий чеков и этикеток. Запрашивается при выборе
файла.

## 4. Чего в приложении нет

Ни одно из этих разрешений не заявляется и не должно появиться без
отдельного решения: фоновая геолокация, контакты, микрофон, календарь,
телефон, SMS, точные идентификаторы устройства.

---

## Проверка перед публикацией

1. Установить сборку на чистое устройство, открыть карточку вина —
   **системный запрос геолокации не должен появиться**.
2. Нажать значок в «Где купить» — появляется объяснение, и только после
   «Разрешить доступ» показывается системный диалог.
3. Отказаться — приложение работает, расстояний нет, маршрут по-прежнему
   открывается.
4. В профиле строка «Расстояние до магазинов» показывает «выключено».
