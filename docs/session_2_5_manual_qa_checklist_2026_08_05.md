# Session 2.5 — ручной чеклист приёмки

Дата: 05.08.2026
Что проверяем: срез A (иерархия Atlas и исключения релиза), срез B (seed
ароматов и сочетаний), срезы D/E (предложения и применение), этап 4 (карточка
читает структурированные знания, экспертный режим), возврат флага страны.

Роль: полный администратор. Где нужен обычный пользователь — отмечено отдельно.

## 0. Состояние данных на момент проверки

Это важно, иначе часть пунктов будет выглядеть как баг:

- в Атласе **71 термин**: 49 ароматов и 22 сочетания, все опубликованы;
- предложений в очереди **2 902**, из них 2 565 сопоставлены с терминами;
- реально применены только **12 назначений на двух винах**:
  «Шираз. Блэк Аут» — 9 ароматов, «Мысхако. Каберне Совиньон. Блэк Аут» — 3;
- сочетания, методы, регионы и награды в карточки **ещё не применялись**;
- назначений уровня релиза и исключений пока нет — их нужно создать вручную
  по разделу 3.

**Панели модерации предложений нет** — это срез F, он не делался. Предложения
сейчас существуют только в базе, применяются SQL-командой. Поэтому в чеклисте
нет пунктов про приём предложений через интерфейс.

| 1.2 | Сравнить с блоком **«ВИНОДЕЛЬНЯ»** ниже | Там география тоже «страна · регион», но **без флага** — он не дублируется |

## 2. Карточка: структурированные ароматы

Эталон — **«Шираз. Блэк Аут»**.

| № | Действие | Ожидаемо |
|---|---|---|
| 2.1 | Открыть «Шираз. Блэк Аут», блок **«АРОМАТ»** | Девять ароматов с иконками: Ваниль, Вишня, Ежевика, Кофе, Лакрица, Тёрн, Чернослив, Чёрный перец, Шоколад |
| 2.2 | Сверить с текстовым описанием вина | Ароматы соответствуют тому, что написано в описании |
| 2.3 | Тапнуть по любому аромату | Открывается шторка с названием и пояснением |
| 2.4 | Открыть «Мысхако. Каберне Совиньон. Блэк Аут» | Три аромата: Вишня, Чёрная смородина, Чернослив |
| 2.5 | Открыть любое другое вино с заполненным полем «Аромат» | Ароматы по-прежнему показываются — из старой строки, как раньше |
| 2.6 | Открыть вино вообще без ароматов | Блок «АРОМАТ» отсутствует, пустой рамки нет |

Пункт 2.5 — ключевой: он подтверждает, что старые данные не пропали.

## 3. Исключение термина у релиза

Данных для этого пока нет, их нужно создать. Понадобится вино с релизом.

| № | Действие | Ожидаемо |
|---|---|---|
| 3.1 | Открыть редактирование вина «Шираз. Блэк Аут», раздел **«Характеристики и знания»** | Видны девять ароматов уровня вина |
| 3.2 | В списке релизов нажать иконку со звёздочками (подсказка «Характеристики и награды релиза») | Открывается «Характеристики релиза …» |
| 3.3 | В этом окне у любого унаследованного аромата открыть меню «⋮» | Пункт **«Не относится к этому релизу»** |
| 3.4 | Нажать его | Диалог «Не относится к этому релизу?» с текстом, что вино и другие релизы не изменятся |
| 3.5 | Подтвердить **«Исключить из релиза»** | Аромат становится зачёркнутым с подписью «не относится к этому релизу» |
| 3.6 | Открыть публичную карточку и выбрать **этот** релиз | Исключённого аромата в блоке «АРОМАТ» нет |
| 3.7 | Переключить на состояние «Все» | Аромат снова виден — у вина он остался |
| 3.8 | Переключить на **другой** релиз | Аромат виден — исключение действует только на своём релизе |
| 3.9 | Вернуться в «Характеристики релиза», меню «⋮», **«Вернуть в релиз»** | Аромат перестаёт быть зачёркнутым, в карточке появляется снова |

Пункты 3.7 и 3.8 — самые важные: они проверяют, что исключение не разрушает
общие данные вина.

## 4. Назначение аромата конкретному релизу

| № | Действие | Ожидаемо |
|---|---|---|
| 4.1 | В «Характеристики релиза …» нажать **«Добавить»** в разделе «Термины Atlas» | Открывается «Добавить характеристику» |
| 4.2 | Выбрать термин, например «Малина», сохранить | Появляется в списке без пометки «От вина» |
| 4.3 | Публичная карточка, выбран этот релиз | «Малина» показывается **первой** — отличия релиза идут впереди унаследованных |
| 4.4 | Состояние «Все» | «Малины» нет: свойство релиза не выдаётся за свойство всего вина |

## 5. Иерархия Atlas

Вход: админка → **«WinePool Atlas»**.

| № | Действие | Ожидаемо |
|---|---|---|
| 5.1 | Найти «Вишня», открыть | Раздел **«Иерархия Atlas»** раскрыт, в «Родители» два чипа: «Красные ягоды» и «Косточковые фрукты» |
| 5.2 | Открыть «Красные ягоды» | В «Дочерние термины» — Вишня, Малина, Красная смородина, Брусника, Клюква со счётчиками назначений |
| 5.3 | В списке **«Добавить родителя»** посмотреть варианты у «Красные ягоды» | В списке **нет** самой «Красные ягоды» и нет её потомков — цикл создать нельзя |
| 5.4 | У аромата попробовать добавить родителя из сочетаний | Сочетаний в списке нет вообще — только термины того же типа |
| 5.5 | У «Вишня» удалить родителя «Косточковые фрукты» крестиком | Чип исчезает; счётчик назначений у «Вишня» **не изменился** |
| 5.6 | Вернуть родителя обратно | Связь восстановлена |

Пункт 5.5 проверяет главное правило: правка иерархии не трогает назначения вин.

## 6. Подавление общего термина частным

| № | Действие | Ожидаемо |
|---|---|---|
| 6.1 | Назначить вину «Вишня» и «Красные ягоды» через редактор вручную | Оба видны в карточке — они внесены независимо, а не из одного фрагмента |

Автоматическое подавление срабатывает только когда оба термина пришли из
**одного и того же** фрагмента описания, то есть после применения предложений.
Вручную такой случай не воспроизвести — он закрыт автотестом.

## 7. Экспертный режим

| № | Действие | Ожидаемо |
|---|---|---|
| 7.1 | Профиль → выключить «Экспертный режим». Открыть «Шираз. Блэк Аут», тапнуть аромат | В шторке только название и пояснение. Блока «ИСТОЧНИК ДАННЫХ» нет |
| 7.2 | Включить «Экспертный режим», повторить | Появился блок **«ИСТОЧНИК ДАННЫХ»**: «Извлечено из описания каталога, подтверждено модератором», цитата фрагмента и «Уверенность источника: 78%» |
| 7.3 | Сверить цитату с описанием вина | Это тот самый фрагмент, из которого извлечён аромат |
| 7.4 | Тапнуть аромат у вина со **старой строкой** (не «Блэк Аут») при включённом режиме | Блока «ИСТОЧНИК ДАННЫХ» нет — у старой строки источника не существует |
| 7.5 | Кнопка «Открыть источник» | У legacy-фактов её нет: ссылки в старых описаниях отсутствуют. Появится после применения фактов из v3-отчётов |
