# WinePool: Консоль процветания

Дата: 05.07.2026

## Что это за сервис

Консоль процветания - это локальная рабочая панель для ручного outreach: винодельни, экскурсионные бюро, партнеры, личные контакты, платные задачи и поддержка проекта.

Сервис не отправляет сообщения сам. Он помогает:

- видеть, кому писать следующим;
- хранить контакты;
- копировать готовый текст сообщения;
- отмечать результат касания;
- записывать живые лиды;
- фиксировать дневную сводку;
- расширять очередь новыми винодельнями из CSV.

Главная идея: не держать все в голове и не терять статусы.

## Где что лежит

Основной интерфейс:

- `tool/crisis_dashboard/server.js` - локальный сервер и логика работы с CSV;
- `tool/crisis_dashboard/public/index.html` - страница панели;
- `tool/crisis_dashboard/public/app.js` - поведение интерфейса;
- `tool/crisis_dashboard/public/styles.css` - стили.

Рабочие данные:

- `docs/crisis_outreach_send_tracker_2026_06_27.csv` - очередь отправок и статусы;
- `docs/crisis_lead_handoff_tracker_2026_06_27.csv` - живые лиды/заявки;
- `docs/crisis_daily_metrics_2026_06_27.csv` - дневные сводки;
- `docs/crisis_target_accounts_tracker_2026_06_27.csv` - расширенный список целевых аккаунтов/виноделен.

Импорт виноделен:

- `docs/crisis_winery_import_template_2026_07_05.csv` - шаблон входного файла;
- `scripts/import_winery_targets.ps1` - скрипт импорта;
- `docs/crisis_winery_import_runbook_2026_07_05.md` - отдельная короткая инструкция по импорту.

## Как запустить панель

Открыть PowerShell в корне проекта:

```powershell
cd R:\Flutter\Project\winepool_final
```

Запустить локальный сервер:

```powershell
node tool\crisis_dashboard\server.js
```

После запуска в терминале должна появиться строка:

```text
WinePool prosperity console: http://127.0.0.1:8787
```

Открыть в браузере:

```text
http://127.0.0.1:8787/
```

Остановить сервер можно в терминале сочетанием:

```text
Ctrl+C
```


Открывать тогда:

```text

```

## Как устроена главная панель

### Следующее действие

Это карточка сверху слева. Она показывает ближайшую строку из очереди со статусом `new`.

В карточке видно:

- ID строки, например `fw07` или `ww001`;
- сегмент: партнеры, гости, платные задачи, поддержка;
- канал контакта;
- ссылка, которую нужно отправить;
- вопрос/цель касания;
- текущий статус.

Ниже находится текст сообщения. Его можно скопировать кнопкой `Скопировать`.

### Можно отправлять сейчас

Этот блок показывает ближайшую строку со статусом `new`, у которой уже заполнен контакт.

Это удобно, если в очереди выше есть строка без контакта: панель сразу подсказывает, кого можно реально отправить прямо сейчас.

Кнопки:

- `Скопировать готовое` - копирует блок: кому, куда, ссылка, текст;
- `Отметить готовое отправленным` - сразу ставит этой строке статус `Отправлено`.

### Куда писать

Поле для контакта текущей строки.

Туда можно внести:

- Telegram username;
- телефон;
- WhatsApp/Telegram ссылку;
- email;
- ссылку на форму или чат.

После ввода нажать `Сохранить контакт`.

### Очередь

Таблица всех касаний.

В ней можно:

- быстро вписать контакт в строку;
- нажать `OK`, чтобы сохранить контакт;
- отметить строку как отправленную;
- отметить ответ;
- отметить платную задачу;
- поставить `Не сейчас`.

## Ежедневный рабочий сценарий

### 1. Запустить панель

```powershell
cd R:\Flutter\Project\winepool_final
node tool\crisis_dashboard\server.js
```

Открыть:

```text
http://127.0.0.1:8787/
```

### 2. Посмотреть "Следующее действие"

Если контакт уже есть:

1. Нажать `Скопировать блок` или `Скопировать`.
2. Вставить сообщение в Telegram, WhatsApp, почту или форму.
3. Отправить вручную.
4. Вернуться в панель.
5. Нажать `Отметить отправлено`.

Если контакта нет:

1. Найти контакт вручную: сайт, Telegram, телефон, форма.
2. Внести в поле `Куда писать`.
3. Нажать `Сохранить контакт`.
4. Скопировать сообщение и отправить.
5. Отметить отправку.

### 3. Обработать ответ

Если человек ответил, нажать `Ответил`.

Если из ответа видно, что это потенциальный партнер или платный интерес, лучше дополнительно записать лид в правой колонке в блоке `Живой лид`.

### 4. Записать живой лид

В блоке `Живой лид` выбрать тип:

- `Платная задача` - если человеку нужна разработка, сайт, форма, админка, доработка;
- `Маршрут` - если человек хочет винный маршрут/дегустацию;
- `Партнер` - если винодельня, бюро, гид или оператор готовы обсуждать пилот;
- `Поддержка` - если человек готов поддержать проект деньгами или ресурсом;
- `Интро` - если человек может познакомить с нужным контактом.

Заполнить:

- `Контакт` - куда отвечать;
- `Сумма, если есть` - можно оставить `0`;
- `Суть` - что хочет человек и какой следующий шаг.

Нажать `Записать лид`.

Лид появится в `docs/crisis_lead_handoff_tracker_2026_06_27.csv`.

### 5. В конце дня записать сводку

В правой колонке есть блок `Дневная фиксация`.

1. В поле `Заметка` написать коротко, что произошло.
2. Нажать `Записать сводку дня`.

Сервис сам посчитает:

- сколько было касаний по сегментам;
- сколько ответов;
- сколько лидов;
- сколько денежных сигналов;
- какой следующий фокус.

Сводка записывается в `docs/crisis_daily_metrics_2026_06_27.csv`.

## Статусы

В интерфейсе статусы показаны на русском, но в CSV они хранятся техническими значениями.

| В интерфейсе | В CSV | Когда ставить |
| --- | --- | --- |
| Новый | `new` | Еще не писали |
| Отправлено | `sent` | Сообщение отправлено вручную |
| Ответил | `replied` | Получен любой живой ответ |
| Созвон запланирован | `call_planned` | Договорились о звонке/встрече |
| Кандидат на пилот | `pilot_candidate` | Партнер потенциально готов проверять модель |
| Денежный сигнал | `money_signal` | Есть шанс на оплату, заявку, сделку |
| Платная задача | `paid_work_lead` | Появился лид на короткую paid-work задачу |
| Поддержка / интро | `support_signal` | Готовы поддержать или познакомить |
| Не сейчас | `no_now` | Ответили, что сейчас неактуально |
| Закрыто | `dead` | Не имеет смысла возвращаться |

Сейчас из интерфейса быстрыми кнопками доступны основные действия: `Отправлено`, `Ответил`, `Платная задача`, `Не сейчас`.

## Сегменты

| Сегмент в интерфейсе | В CSV | Что это |
| --- | --- | --- |
| Партнеры | `local_partner` | Винодельни, операторы, экскурсионные бюро, гиды |
| Запросы гостей | `tourist_demand` | Люди/каналы, где можно получить спрос на маршруты |
| Платные задачи | `paid_work` | Быстрые задачи на 1-5 дней для выручки |
| Поддержка | `support` | Поддержка проекта, интро, помощь |

## Как выбирать, кому писать

В текущей логике приоритет такой:

1. Теплый базовый партнер `Еду в Ялту`.
2. Готовые контакты по локальным партнерам.
3. Личные контакты и запросы гостей.
4. Платные задачи, если нужен быстрый cash.
5. Поддержка и интро.
6. Резервные крупные/холодные игроки позже.

Крупных игроков вроде Массандры, Wine Park, Инкермана лучше не ставить в первые касания, если нет теплого входа. Они могут быть полезны позже, но цикл согласования у них тяжелее.

## Как добавлять винодельни из таблицы

### 1. Подготовить CSV

Файл должен быть в формате шаблона:

```text
docs/crisis_winery_import_template_2026_07_05.csv
```

Колонки:

- `name` - название;
- `organization` - полное название, можно повторить `name`;
- `city` - город/район;
- `source_url` - сайт, соцсеть или источник;
- `contact_channel` - `phone`, `email`, `telegram`, `site_form`, `phone_email`;
- `contact_value` - телефон, email, Telegram, ссылка;
- `has_tasting` - `yes`, `no`, `unknown`;
- `accepts_groups` - `yes`, `no`, `unknown`;
- `scale` - `small`, `medium`, `large`, `unknown`;
- `priority` - `high`, `medium`, `low`, можно оставить пустым;
- `notes` - важные заметки.

### 2. Сначала сделать сухую проверку

```powershell
pwsh -NoProfile -File scripts\import_winery_targets.ps1 -SourcePath "R:\path\to\wineries.csv" -DryRun
```

Это покажет, сколько строк будет добавлено, но файлы не изменит.

### 3. Добавить только в общий target tracker

```powershell
pwsh -NoProfile -File scripts\import_winery_targets.ps1 -SourcePath "R:\path\to\wineries.csv"
```

Так винодельни попадут в `docs/crisis_target_accounts_tracker_2026_06_27.csv`, но не попадут сразу в очередь отправки.

### 4. Добавить в очередь outreach

```powershell
pwsh -NoProfile -File scripts\import_winery_targets.ps1 -SourcePath "R:\path\to\wineries.csv" -AddToOutreach
```

### 5. Добавить только ограниченное количество

Например, первые 25 подходящих строк:

```powershell
pwsh -NoProfile -File scripts\import_winery_targets.ps1 -SourcePath "R:\path\to\wineries.csv" -AddToOutreach -MaxOutreach 25
```

Новые строки в outreach получат ID с префиксом `ww`, например `ww001`, `ww002`.

## Как сервис решает, что приоритетно

Если в CSV явно указан `priority`, используется он.

Если приоритет пустой, скрипт сам оценивает:

- `high` - есть контакт, есть дегустации, группы не запрещены, хозяйство малое или среднее;
- `medium` - контакт есть, но что-то нужно уточнить, либо объект крупный;
- `low` - нет контакта, нет признака дегустаций или нужен отдельный ресерч.

## Как менять текст сообщений

Тексты сообщений находятся в `tool/crisis_dashboard/server.js` в блоке `templates`.

Основные шаблоны:

- `operator_warm_base` - теплый базовый партнер;
- `partner_short` - винодельни и партнеры;
- `operator_short` - экскурсионные бюро/операторы;
- `tourist_short` - гости/личные контакты;
- `community_soft` - каналы/сообщества;
- `paid_work_short` - платные задачи;
- `support_soft` - поддержка проекта.

Для некоторых paid-work строк есть персональные тексты в блоке `paidWorkMessages`.

После изменения текста нужно остановить и заново запустить сервер.

## Частые проблемы

### Панель не открывается

Проверить, запущен ли сервер:

```powershell
node tool\crisis_dashboard\server.js
```

Проверить адрес:

```text
http://127.0.0.1:8787/
```

Если порт занят, запустить на другом порту:

```powershell
$env:PORT=8788
node tool\crisis_dashboard\server.js
```

### Кнопка не сохраняет данные

Обычно причина в том, что сервер не запущен или был остановлен.

Решение:

1. Проверить терминал с сервером.
2. Если сервер упал, запустить заново.
3. Обновить страницу.

### После ручной правки CSV панель показывает ошибку

Частая причина - сломалась CSV-структура: лишняя запятая, кавычка или перенос строки.

Что делать:

1. Открыть файл в редакторе.
2. Проверить последнюю измененную строку.
3. Если в поле есть запятые или переносы, обернуть поле в кавычки.
4. Если есть кавычки внутри поля, удвоить их.

Пример:

```csv
notes
"Ответил: ""напишите завтра"", нужен follow-up"
```

### Импорт добавил не то

Если перед импортом была сделана копия, вернуть нужный CSV.

Если копии нет, можно вручную удалить добавленные строки `ww001`, `ww002` и так далее из:

- `docs/crisis_target_accounts_tracker_2026_06_27.csv`;
- `docs/crisis_outreach_send_tracker_2026_06_27.csv`, если использовался `-AddToOutreach`.

## Минимальный рабочий ритм на день

Если нет сил на полную систему, достаточно такого минимума:

1. Открыть панель.
2. Сделать 3-5 касаний по готовым контактам.
3. Каждый отправленный контакт отметить как `Отправлено`.
4. Каждый ответ записать как `Ответил`.
5. Любой реальный интерес сразу записать в `Живой лид`.
6. Вечером нажать `Записать сводку дня`.

Главное правило: если был живой контакт, он должен остаться либо в статусе, либо в лидах, либо в дневной заметке. Тогда ничего не пропадает.
