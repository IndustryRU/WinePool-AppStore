## 2. Ручная матрица (release-сборка)

Легенда: ☐ не проверено · ✅ ок · ❌ дефект (с заметкой).

### 2.1. Текстовый поиск («Добавить бутылку → Найти в каталоге», matcher)
- ✅ exact: точное название → кандидат(ы) с действием добавить/открыть
  (подтверждено 25.07);
- ✅ typo-tolerance: опечатка/короткий запрос («proseco», «prosseco», «pro»)
  находит вино (нечёткий поиск pg_trgm; подтверждено 25.07);
- ✅ candidates: близкие варианты → карточки-кандидаты (сигнал «Совпадение по
  названию»; расширенные «Почему/Что проверить» — для label/barcode);
- no-match — принятое поведение (владелец, 25.07): одна кнопка «Добавить вино,
  которого нет в каталоге» → экран черновика; отправка в общий каталог
  управляется тумблером внутри (авто-включение по достаточности данных, иначе
  можно отправить позже); черновик создаётся только по явному действию. Двух
  отдельных кнопок §15.4 намеренно не делаем.
- ✅ широта: винодельни и сорта по-прежнему находятся (в лупе — подстрока; в
  matcher канал wine-only).

> Примечание: широкий поиск под лупой (`SearchResultsScreen`) — отдельный экран
> (вина+винодельни+сорта, для изучения); вина в нём тоже ищутся нечётко. Это не
> matcher добавления; не путать при прогоне.

### 2.2. Штрихкод — ✅ закрыто Codex/Products, принято владельцем (29.07)
- ✅ verified exact: один verified-код → краткий результат с конкретным релизом,
  без молчаливого добавления;
- ✅ legacy exact: перенесённый `wines.barcode` → тот же exact-путь;
- ✅ conflict: несколько связей/явный конфликт → показаны все варианты и причина;
- ✅ same-wine shared GTIN: общая связь без `wine_vintage_id` → показаны чипы
  только существующих релизов, `NV`, если он реально существует, а также
  `Не вижу год` и `Нет нужного года`; релиз не выбирается молча;
- ✅ OCR suggestion: распознанный год лишь выделен как рекомендация, пользователь
  может выбрать другой существующий релиз;
- ✅ pending-only: только pending-связи → `no-reliable-match`, никогда не exact;
- ✅ absent: неизвестный код не трактуется как отсутствующее вино; сначала
  предложены поиск по названию и этикетке, отдельно — явное предложение нового
  вина и повторное сканирование.
