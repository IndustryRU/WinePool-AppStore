# Инструкция для создания Kwork-обложек и промо-картинок

Эта инструкция обязательна, если пользователь ссылается на нее при создании обложки или промо-картинки для Kwork.

## Главный принцип

Делать **один готовый визуальный артефакт за раз**.

Не делать пачку вариантов, контакт-листы, несколько размеров, превью-таблицы или служебные картинки, если пользователь прямо не попросил.

## Рабочий подход

Использовать комбинированный вариант:

1. **ImageGen** — только для красивого фона/сцены без текста, без UI, без логотипов и без сгенерированных экранов.
2. **Ручная сборка поверх фона** — реальные скриншоты приложения, нормальный русский текст, плашки, тени, рамки.

Русский текст нельзя доверять ImageGen. Его нужно накладывать вручную через Pillow/другой контролируемый инструмент.

## Что делать перед началом

1. Уточнить или принять разумно:
   - размер итоговой картинки;
   - главный текст;
   - какие 2-3 экрана использовать;
   - что должно быть главным преимуществом.
2. Если пользователь сказал “одна обложка” — сделать только одну обложку.
3. Если пользователь сказал “один размер” — сохранить только один файл.

## Запрещено

- Не делать контакт-лист.
- Не писать на картинке имена файлов, пути, номера вариантов или технические подписи.
- Не создавать 5 размеров без запроса.
- Не ставить два одинаковых экрана рядом.
- Не класть белый текст на светлый фон.
- Не накладывать текст на скриншоты.
- Не допускать, чтобы плашки, телефоны и текст пересекались.
- Не делать мелкий нечитаемый текст ради “красоты”.
- Не генерировать UI через ImageGen, если есть реальные скриншоты.
- Не продолжать серию картинок, пока первая не согласована.

## Требования к композиции

- Формат: один чистый финальный PNG.
- Левая зона: крупный оффер и 3-5 коротких преимуществ.
- Правая зона: 2-3 реальных экрана приложения в аккуратных мокапах.
- Фон: темный, премиальный, бордовый/золотой, без визуального шума.
- Текст: крупный, контрастный, читаемый на масштабе Kwork.
- Скриншоты: не перекрывают главный текст и не закрывают друг друга критично.

## Рекомендуемый текст для обложки

Главный заголовок:

```text
Мобильные приложения под ключ
```

Подзаголовок:

```text
Flutter + Supabase + backend + VPS
```

Короткие преимущества:

```text
ПОЛНЫЙ ЦИКЛ
BACKEND + VPS
WEB-ВЕРСИЯ
ТЕСТОВЫЕ APK
ПОНЯТНЫЙ ПРОЦЕСС
```

## Проверка перед ответом пользователю

Перед финальным сообщением открыть готовую картинку и проверить:

1. Нет ли служебных подписей.
2. Нет ли пересечений текста и экранов.
3. Нет ли белого текста на светлом фоне.
4. Нет ли дублей экранов рядом.
5. Читается ли главный заголовок.
6. Создан ровно один финальный файл.

## Как отвечать пользователю

После создания не расписывать лишнего. Дать ссылку на один готовый файл и коротко сказать, что именно сделано.

Пример:

```text
Сделал одну обложку 1320×880 без вариантов и служебных подписей:
[kwork_cover.png](...)
```
