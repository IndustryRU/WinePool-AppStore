  выпуску и позиции, слияние с чеками, `distance_m`;
- `app_feature_flags` и флаг `nearby_places_distance`;
- фото на уровне позиции (`wine_vintage_images.wine_sku_id`);
- `get_wine_volume_options` — объёмы вина для карточки;
- гейт публикации: писать предложения может только подтверждённый продавец;
- `business_members` — закладка под кабинет продавца.

Интерфейс:

- админка: вывески, точки продаж, предложения, переключатели объёма в
  менеджере выпусков, кнопка «Создать продавца»;
- карточка вина: выбор объёма с ценой «от», пересчёт фото и цены, свёртка по
  сети в «Где купить», расстояние и маршрут за флагом;
- кабинет продавца: вкладка предложений заменена честной подписью, мобильные
  экраны предложений удалены вместе с маршрутами.

Уборка:

- удалены `add_offer_screen`, `edit_offer_screen`, `offers_repository`,
  `offers_controller`, `all_offers_controller` и мёртвые провайдеры цены;
- удалены 5 тестовых бизнесов, роль `seller` снята с 4 профилей;
- дубль `formatBottleVolume` схлопнут в один.

точки спорили за строку, импорт CSV молча съедал файлы с переносами `\n`.

- **Каталог и карточка вина падали в бою.** Строки выборки просили
  `offers.vintage`, удалённый при пересборке: живой API отвечал 400 на
  `fetchWine` — открытие вина по ссылке, из поиска, с карты, из чека и из
  админки. Починено в трёх местах (каталог, карточка, избранное).
  Урок повторный: при удалении колонки проверять **читателей**, а не только
  пишущих.
- **Дыра в правах на предложения** (§6.2 ТЗ) — закрыта.
- **Отложенная дыра**: право писать предложения не смотрело на подтверждение
  бизнеса. Закрыто до открытия кабинета, а не после.
- **Дефект `user_receipts.shop_geo_key`** — зафиксирован в ТЗ §5.5, не
  переписан намеренно.
